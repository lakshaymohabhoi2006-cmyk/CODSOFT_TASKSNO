# Job Board

A responsive job board built for the CodSoft Level 2 Web Development Internship.

## Live website

https://codsoft-tasksno-theta.vercel.app/

## About

The project lets visitors browse job openings, search for positions, view job details, and try the application flow. It also includes candidate and employer sections with login and registration screens.

## Features

- Searchable job listings
- Job details pages
- Application form
- Candidate login and registration
- Candidate dashboard
- Employer dashboard
- Responsive layout for mobile and desktop
- Sample job and application data

## Built with

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

This version is a frontend demonstration using sample data. Login, registration, and job applications are not connected to a live backend database.
