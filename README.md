# CodSoft Level 2 Web Development Tasks

This repository contains my projects for Level 2, Tasks 1 and 2.

## Task 1: Job Board

A Next.js job board with searchable listings, job details, an application form, sign-in and registration screens, and candidate and employer dashboards.

**Live site:** [Open the Job Board](https://codsoft-tasksno-theta.vercel.app/)

To run it locally, install the dependencies and start the development server from the repository root:

```bash
npm install
npm run dev
```

The Job Board uses sample data. Sign-in, registration, and job applications are demo features and are not connected to a backend.

## Task 2: Online Quiz Maker

A React quiz app with an Express API and MongoDB support. Create quizzes, answer questions, and review your score.

**Local app:** `http://localhost:5173`

The quiz maker is ready to deploy as a separate Vercel project. Open the Vercel project with `online-quiz-maker` as its root directory. Deployment details are in [`online-quiz-maker/README.md`](./online-quiz-maker/README.md).
